Программно-инструментальный комплекс визуальной дефектоскопии на конвейерной линии (Webots + YOLOv8n-OBB + GhostConv)
### Стек технологий
Webots R2025a — симуляция конвейерной линии, YOLOv8n-OBB — нейросетевая модель детекции дефектов, GhostConv — оптимизация модели (снижение количества параметров), ZMQ — передача видеопотока, Tkinter + Matplotlib — графический интерфейс оператора, Python 3.10+

### Основные возможности
Симуляция конвейерной линии с тремя типами изделий, Детекция дефектов в реальном времени (две камеры: фронтальная и боковая), Графический интерфейс с отображением статистики
